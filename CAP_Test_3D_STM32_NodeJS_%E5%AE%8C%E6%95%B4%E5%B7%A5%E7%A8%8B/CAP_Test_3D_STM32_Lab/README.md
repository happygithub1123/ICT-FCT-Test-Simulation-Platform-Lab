# CAP Test 3D + STM32 ADC 全链路演示（V3.0）

纯 HTML / JavaScript、本地离线可运行，没有 CDN 或第三方依赖。

## 一键运行

- **单 HTML**：双击 `CAP_Test_3D_STM32_单文件演示.html`，用 Chrome/Edge 打开。
- **Node.js 工程**：VS Code 打开此文件夹，在终端输入 `npm start`，浏览器访问 `http://127.0.0.1:5173/`。
- 环境 Node.js 18+，不需要 `npm install`。

## 文件说明

- `index.html`：测试台、STM32 3D PCB 展示、ADC 及软件状态面板。
- `style.css`：暗色大屏视觉与响应式布局。
- `renderer3d.js`：不依赖 Three.js 的三维场景、手势交互、透视投影、48 引脚 STM32 封装与动态信号。
- `app.js`：恒流充放电模型、ADC 12-bit 量化、1 ms 定时采样判定、曲线与结果计算。
- `server.js`：Node 原生 HTTP 服务。

## 演示工作流程

1. 激励源输出恒流 `I`，电容电压按 `dUc/dt = I / C` 上升。
2. 电容端电压经示意的分压比 `K = 3 / 4.2`，输入 `PA0 / ADC1_IN0`。`Uadc = K × Uc`，最高 4.2V 被映射到 3.0V。
3. 以 1 ms 为采样周期，采样值通过 12-bit ADC 量化为 0~4095 整数。
4. STM32 固件比较采样值是否达到相当于 1.0V（A）、3.0V（B）的阈值码，按**首个合格采样时刻**记录 `t1` / `t2`。
5. `C(µF) = 1000 × I(mA) × (t2 - t1)(s) / 2.0(V)`。由于 1ms 离散采样和 ADC 量化，容量可能出现小的离散误差，这是正常现象。
6. 达到 4.2V 后保持 0.4s、转为反向恒流放电，UART 可视面板显示结果。

**示例**：I=2mA、Cx=1000µF 时，t1≈0.5s、t2≈1.5s、结果≈1000µF。

## 教学边界

- 3D 芯片、PCB、信号走线是**演示模型**，不等于已经验证的完整 PCB 原理图或实际引脚布线。
- **STM32F103C8T6**、PA0/ADC1_IN0 与 TIM1 的采样链为可实施的设计方向，但需要按芯片手册合理配置 ADC 外部触发源和定时器（亦可通过定时器中断软件启动采样）。动画属于概念级功能仿真，**不是**已编译运行在真机上的固件。
- 仿真不含 ESR、漏电、噪声、采样保持时间、内部 ADC 通道切换串扰、激励源瞬态与安全限流。
- 注意 ADC 输入最大额定范围及 VDD/VDDA，实际电路需要分压、输入保护与合理参考电压。
