电容测量原理 / CAPACITANCE BY CONSTANT CURRENT

不仅看见充放电，还看见 STM32 在做什么。

通过可调直流恒流激励源向被测电容注入或抽取恒定电流，同时用STM32 定时触发 ADC采样电容端电压。系统在 1.0 V 和 3.0 V 两个阈值处记录 t₁、t₂，再由 MCU 根据 C = I × Δt / ΔV 自动计算电容值，并可视化显示整个内部处理过程。

TEST EQUATION
C = I × ΔtΔV
I = C × dV/dt STM32 在阈值采样窗口内完成计时与运算

06 — EXPERIMENT SEQUENCE

一次 CAP Test 的实际步骤

01探针连接夹具将恒流激励源与电压采样网络并接至 Cx 两端。
02恒流充电电流 I 恒定，电容电压以 I/C 斜率上升。
03ADC 连续采样STM32 通过 TIM1 周期触发 ADC1，持续观察 Uc。
04阈值锁存越过 1 V、3 V 时分别记录 t₁、t₂。
05计算与显示MCU 执行 C = IΔt/ΔV，输出结果并受控放电归零。
仿真边界：真实外形的教学 3D 模型，非实测数据。假设理想双向恒流源、理想电容、理想分压电阻和 12-bit ADC 量化；按固定 1ms 采样节拍判定阈值。未模拟 ESR、漏电流、ADC 噪声、DMA 中断延迟、采样保持电容、寄生参数与实际切换瞬态。 · 100% 本地运行，无 CDN 依赖。
