# DiodeLab 3D v2.0 — FCT 二极管 / 双向ESD击穿与ADC测试仿真平台

## 启动方法（Windows + Node.js）

方法一（推荐）：双击 `DiodeLab_Standalone.html`，Chrome / Edge 本地打开，不需要服务器、联网或npm。

方法二：在工程目录打开 Git Bash、PowerShell 或 CMD：

```bash
node server.js
```

**终端应保持运行，不要按 Ctrl+C**。然后在浏览器打开：

```text
http://127.0.0.1:5173/
```

如果5173被占用：

```bash
# Git Bash
PORT=5174 node server.js

# PowerShell
$env:PORT=5174; node server.js
```

访问 `http://127.0.0.1:5174/`。

## 与 v1 相比新增的能力

- 以当前FCT测试截图的 `ESD245-B1-W0201 / D500` 作为默认器件：
  - 正向 `D500_Vf`：**+5.8～+8.1V**
  - 反向 `D500_Rf`：**−8.1～−5.8V**
  - **1mA** 目标恒流；**12V** 作为恒流源顺从电压上限（对此术语的解读需要与ERS核对）
- 保留原生WebGL 3D治具，增加双向击穿/钳位的紫色发光、环形电场、放电路径特效（不是器件损坏）。可鼠标拖动旋转、滚轮缩放、双击复位。
- 提供9种示意器件：当前ESD、通用双向TVS、单向TVS、Zener、普通硅整流、小信号、肖特基、LED、光电二极管。
- 实时电压-时间曲线、**每个极性独立的正负数上下限线**、独立的I-V特性曲线和动态工作点。
- MCU采集动画：恒流源→继电器→DUT→AFE（极性转换、绝对值1/5衰减）→10位ADC（3.3V参考）→16次采样平均→上下限/实际电流检测。
- 可修改四个带符号上下限、测试电流、顺从电压、动画速度。
- 注入正常、偏低、偏高、短路、开路情形，演示 PASS/FAIL/INVALID：**到达12V但没有建立1mA应为INVALID**，不能误报“反向击穿”。
- 正反向自动/单独测试；模拟结果可以导出UTF-8 BOM CSV。

## 操作示例

1. 不更改参数直接点 **一键正反向自动测试**。
2. 正向目标约 +6.43V，反向约 −6.52V；均在截图范围内，预期PASS（示意模型）。
3. 将故障注入切为“低于下限”，重新运行，观察红色 FAIL 与上下限线。
4. 切为“器件开路”，重新运行，观察达12V输出上限但电流不足、ADC采集仍显示电压而判为 INVALID。
5. 选“普通硅整流二极管”并运行反向：不会把12V限压当成普通二极管的击穿电压，显示 INVALID。
6. 点击“导出CSV结果”保存本次模拟报告。

## 技术细节

- 无需 `npm install`、无需任何第三方CDN。使用原生HTML/CSS/JavaScript与WebGL，WebGL不可用时尝试Canvas软件3D投影。
- 工程文件：`index.html`（页面）、`styles.css`（界面）、`app.js`（模型/引擎）、`server.js`（Node静态服务器）、`DiodeLab_Standalone.html`（独立文件）。
- 教学ADC：`ADCcode = round(|V_DUT| / 5 / 3.3 * 1023)`，反算 `V_DUT ≈ 符号 × 平均ADC码 × 3.3 / 1023 × 5`；同时校验**实际电流**是否到达目标的98%。量化误差/噪声是确定性的演示数据。
- I-V曲线是简化的教学静态特性模型，并非SPICE级精度，也未包含温漂、结电容、动态电阻、热效应、浪涌能量或PCB并联支路。

## 重要：本项目不是实物治具测量程序

仅以用户提供的FCT截图设置D500范围；不能仅凭截图证明ESD245-B1-W0201的厂家级器件分类、实际击穿机理和合规测试电流。现场仍需核对器件完整料号和ERS。

正负两极电压必须通过具备防护的模拟前端进行极性转换和衰减，不能把-8.1V或+12V直接接至MCU ADC输入。恒流源必须有输出限压、电流限制及对反灌和极性切换的保护；真实ADC测量需要完成校准与精度验证。普通LED、光电二极管等不可照搬ESD的反向1mA/12V条件。

**所有读数是JavaScript生成的模拟值，没有连接STC12C5A60S2芯片、串口、真实恒流源或DUT。**
