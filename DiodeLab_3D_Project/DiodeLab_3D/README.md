# DiodeLab 3D — FCT 二极管 / 双向 TVS 恒流测试仿真

纯 HTML + CSS + JavaScript 的可交互教育仿真程序，不需要安装 three.js、npm 依赖或连接网络。3D 场景使用浏览器原生 WebGL 绘制真正的空间几何体，并支持鼠标旋转/缩放。

## 运行

**方法 A（最简单）：** 双击 `index.html`，使用 Chrome 或 Edge 打开。

**方法 B（使用 Node.js）：** 在文件夹里运行：

```powershell
node server.js
```

然后浏览器打开 `http://127.0.0.1:5173/`。服务器用 Node 内置模块实现，无须 `npm install`。

**方法 C：** 也可以直接打开打包外的 `DiodeLab_Standalone.html`，那是 CSS 和 JavaScript 均内嵌的独立 HTML 文件。

## 功能

- 3D 测试板：恒流源、K1/K2 极性切换继电器、二极管/TVS 实物封装、AFE 与 ADC、STC12C5A60S2 MCU、动态电流粒子与采样线路
- 实时测试：一键正反向，或单独正向/反向，调节恒流目标、限压、规格范围和动画速度
- 10bit ADC 示例：Vref=3.3V，输入前端衰减系数 1/5，采样并回算两端电压
- 动态电压曲线、测量仪表、步骤状态机、软件日志、测试报告
- 区分“达到目标恒流”与“达顺从电压上限”：普通硅二极管反向 1mA 通常无法在12V限压下建立，显示 INVALID，而不是误判击穿电压
- 双向 TVS 仅为简化示意模型，在±1mA左右产生约±6.4V电压，**不是对任何真实型号的承诺**

## 物理模型及安全边界

模拟顺序：继电器切换 → 开启恒流源 → 恒流/限压模型 → ADC测量 → MCU比较界限。

这里的二极管、TVS模型为教学说明而简化：真实 TVS 的 VBR 通常以厂商规定的特定测试电流 IT 给出，1mA 不能直接替代规格书测试电流。普通二极管的反向 1mA 激励若要求进入击穿，可能需要危险高压甚至损坏器件。实物治具必须根据 ERS/数据手册配置限制电压、电流、保护/放电、继电器切换死区、隔离与前端耐压。

本工程**不连接真实ADC、真实恒流源或串口**，不能用它的模拟结果作为治具的量测依据。若需要实板联机，需要额外编写 MCU 固件、通信协议和接口桥接。

## 文件说明

- `index.html` — 页面结构
- `styles.css` — 样式与响应式布局
- `app.js` — WebGL 3D 引擎、测量模型、ADC、曲线和状态机
- `server.js` — Node.js 零依赖静态服务器
