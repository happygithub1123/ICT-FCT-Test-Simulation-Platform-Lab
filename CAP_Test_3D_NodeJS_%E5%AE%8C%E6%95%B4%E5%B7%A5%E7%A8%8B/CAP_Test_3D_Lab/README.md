# CAP TEST · 3D 恒流充放电实物演示

## 启动

最简单：Chrome/Edge 双击 `index.html`，无需网络。

Node.js：在本目录打开终端：

```bash
npm start
```

浏览器访问 `http://127.0.0.1:5173/`。

不需要 `npm install`，也不依赖在线 3D 库；Canvas 采用真实三维坐标、透视投影、表面光照和遮挡排序绘制，支持拖动旋转、滚轮缩放。

## 项目文件

- `index.html`：仪表台和参数面板。
- `style.css`：UI 样式和响应式布局。
- `renderer3d.js`：真正的三维几何模型、激励源、电容、数字电压表、3D 测试线、动态电流光点、相机交互。
- `app.js`：恒流充/放电物理模型，数据采样、阈值插值、曲线绘制和 UI 联动。
- `server.js`：Node.js 原生 HTTP 本地服务器。

## 测试流程

1. 双向恒流源为被测电容充电。设置 I、Cx、播放速度及激励源 compliance 电压上限。
2. 监测电容端电压 `Uc`，当电压经过 A=1.0 V 和 B=3.0 V 时，分别记录 `t1`/`t2`。
3. 容量公式 `C(µF) = 1000 × I(mA) × (t2 - t1)(s) ÷ (3.0 - 1.0)(V)`。
4. 在 4.2 V 处停止充电，静置 0.4 s，再以相同幅值的反向电流放电至 0 V。
5. 自动循环可关闭；可直接按「切换充/放电」。

示例：`I=2.0mA`、`Cx=1000µF`，则 `dV/dt=2.0V/s`、`t1=0.5s`、`t2=1.5s`、`Δt=1.0s`、`Cx=1000µF`。

## 注意

这是理想模型、教学用三维实物外观，不是实际实物采集；可见光点显示的是**约定电流方向**，电流不会穿越电容介质。电容上的绿色环仅表示电压/储能程度，**不是电解液位高度**。真实 FCT/ICT 需考虑漏电流、ESR、串联电阻、电压源余量、ADC 噪声、上电初始电压和防过压保护等。
